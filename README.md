# MossNote

MossNote 是一个使用 C++ 和 Qt Widgets 开发的本地 Markdown 笔记应用。笔记以普通 `.md` 文件保存在用户选择的本地文件夹中，便于使用其他 Markdown 编辑器访问和管理。

## 功能

### 笔记编辑

- 在编辑区编写 Markdown，并在预览区实时查看渲染结果。
- 打开本地 Markdown 文件。
- 保存到当前文件；新建的笔记可以选择保存位置。
- 切换笔记或关闭窗口时，对未保存的修改进行提示。
- 使用 UTF-8 读取和保存笔记内容。

### 本地笔记库

- 选择本地文件夹作为笔记库。
- 笔记库对应电脑上的一个文件夹，其中的 Markdown 文件是笔记，子文件夹用于整理笔记。
- 以树状结构浏览笔记库中的文件夹和 `.md` 文件。
- 记住上次选择的笔记库，并在下次启动时尝试恢复。
- 手动刷新笔记库内容。

### 笔记和文件夹管理

- 在笔记库中创建笔记。
- 根据左侧当前选择的位置创建笔记或文件夹：
  - 未选择项目时，在笔记库根目录创建。
  - 选中文件夹时，在该文件夹中创建。
  - 选中笔记时，在该笔记所在文件夹中创建。
- 重命名和删除笔记。
- 删除文件夹前进行确认；文件夹非空时会提示其中的内容也将被删除。
- 展开或折叠笔记库中的文件夹。

### 搜索与排序

- 在侧边栏搜索笔记标题和正文，搜索范围包括子文件夹。
- 点击搜索结果可以打开对应笔记。
- 搜索没有结果时显示提示。
- 按笔记文件名、编辑时间或创建时间排序，并支持升序和降序。排序针对笔记文件；文件夹保持原有位置和顺序。

### 界面

- 三栏工作区：笔记库、Markdown 编辑器和实时预览。
- 侧边栏可收起或展开。
- 侧边栏可在文件列表和搜索模式之间切换。

## 技术栈

- C++17
- Qt 6 Widgets
- CMake
- Git

## 构建与运行

### 使用 Qt Creator

1. 使用 Qt Creator 打开项目根目录中的 `CMakeLists.txt`。
2. 选择已安装的 Qt 6 桌面构建套件，例如 MinGW 或 MSVC。
3. 配置、构建并运行项目。
4. 首次启动时，在菜单中选择一个本地文件夹作为笔记库。

### 使用 CMake

确保已安装 Qt 6 Widgets、CMake 和对应的 C++ 编译器，然后在项目根目录执行：

```bash
cmake -S . -B build
cmake --build build
```

## 快捷键

- `Ctrl + O`：打开 Markdown 文件
- `Ctrl + S`：保存当前笔记
- `Ctrl + F`：进入笔记搜索

## 项目范围

MossNote 目前以本地 Markdown 文件管理和编辑为核心，不包含云同步、标签系统、双链或反向链接。笔记文件由用户保存在本地笔记库目录中。

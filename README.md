# MossNote

MossNote 是一个使用 C++ 和 Qt Widgets 开发的本地 Markdown 笔记应用。

## 主要功能

- 选择本地文件夹作为笔记库
- 以树状结构浏览文件夹和 Markdown 文件
- 编辑 Markdown 并实时预览
- 打开、保存、新建、重命名和删除笔记
- 在切换笔记或关闭窗口时提示未保存的修改
- 按标题和正文搜索笔记
- 自动恢复上次打开的笔记库

## 使用的技术

- C++17
- Qt 6 Widgets
- CMake
- Git

## 如何运行

1. 使用 Qt Creator 打开项目根目录下的 `CMakeLists.txt`。
2. 选择已安装的 Qt 6 桌面构建套件。
3. 构建并运行项目。
4. 在“文件”菜单中选择笔记库文件夹。

## 快捷键

- `Ctrl + O`：打开文件
- `Ctrl + S`：保存文件
- `Ctrl + F`：搜索笔记
